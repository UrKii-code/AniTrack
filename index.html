How to Install AniTrack

Detecting your browser...

Embedded Preview Window Detected

Web browsers block install events inside embedded preview frames. Open AniTrack directly in your browser to enable one-click installation:

Samsung Internet (Galaxy Tablet & Phone)

Samsung Internet provides built-in PWA support with two quick ways to install:

Quick URL Bar Method: Look at the right side of the top address bar. If you see a Down-Arrow Install icon, tap it to install immediately.
Browser Menu Method: 1. Tap the Menu (≡) icon at the bottom-right.
2. Tap Add page to (or "Install web app").
3. Choose Home screen or App screen.
Android Chrome

Chrome allows installing AniTrack as a high-performance standalone Android application:

  1. Tap the Three Dots in the top-right corner of Chrome.
  2. Select Install app (or Add to Home screen).
  3. Tap Install in the confirmation dialog.
iPad & iPhone (Safari)

WebKit does not support automatic prompts; use Safari's native Add to Home Screen option:

  1. Tap the Share button in Safari's top (iPad) or bottom (iPhone) toolbar.
  2. Scroll down the share sheet and tap Add to Home Screen.
  3. Tap Add in the top-right corner to finish.
Desktop (Chrome, Edge, Brave, Opera)

Install AniTrack directly to your Windows, macOS, or ChromeOS taskbar:

  1. Look on the right side of the address bar for the Install App (⊕) icon and click it.
  2. Or click the three dots menu (⋮) -> select Install AniTrack.
  3. Confirm Install to open in a dedicated app window.
